* Definitions

#+label: Def:1
#+name: Def:1
#+begin_definition
Let \(V\) be a finite set. A finite *simplicial complex* \(\Delta\) with vertices in \(V\) is a collection of subsets of \(V\), called *faces*, such that \(A\subseteq B\in\Delta\) implies that \(A\in\Delta\).

If \(A\in\Delta\), we define the *dimension* of \(A\) as \(\dim A=|A|-1\). The dimension of the complex \(\Delta\) is \(\dim\Delta=\max_{A\in\Delta}\dim A\).

We agree that \(\dim\emptyset=-1\).

If \(A,B\in\Delta\) with \(A\subseteq B\), we denote \([A,B]=\{\,C\in\Delta\mid A\subseteq C\subseteq B\,\}\). If \(A\in\Delta\), we denote \(\overline{A}=[\emptyset, A]\).

A subcomplex of \(\Delta\) is a subset of \(\Delta\) that is also a complex. If \(A\in\Delta\), the subcomplex \(\overline{A}\) is called a *simplex*.

The maximal faces of \(\Delta\) with respect to inclusion are called *facets*. A simplicial complex is *pure* if all its facets have the same dimension.
#+end_definition

#+label: exa:standard-simplex
#+name: exa:standard-simplex
#+begin_exampleblock
Let \(V = \{1, 2, 3\}\).
1. Consider \(\Delta_1 = \{ \emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{2,3\}, \{1,3\}, \{1,2,3\} \}\). This is a simplicial complex. It consists of a solid triangle (the face \(\{1,2,3\}\)) and all its subsets. It is pure of dimension 2.
2. Consider \(\Delta_2 = \{ \emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{2,3\}, \{1,3\} \}\). This is also a simplicial complex (the boundary of the triangle). It is pure of dimension 1.
3. Consider \(\Gamma = \{ \emptyset, \{1\}, \{2\}, \{1,2,3\} \}\). This is /not/ a simplicial complex because the subset \(\{1,2\} \subseteq \{1,2,3\}\) is missing.
#+end_exampleblock

#+label: Prop:1
#+name: Prop:1
#+begin_proposition
If \(\Delta\) is a complex and \(\Delta_{1}\), \(\Delta_{2}\) are subcomplexes of \(\Delta\), then \(\Delta_{1}\cap\Delta_{2}\) and \(\Delta_{1}\cup\Delta_{2}\) are also subcomplexes of \(\Delta\).
#+end_proposition

#+label: Def:2
#+name: Def:2
#+begin_definition
A complex \(\Delta\) is *shellable* if its facets can be linearly ordered: \(F_{1},F_{2},\ldots,F_{t}\), in such a way that for \(k=2,\ldots,t\) the subcomplex:

#+name: eq:1
\begin{equation}
\left(\bigcup_{i=1}^{k-1} \overline{F}_{i}\right)\cap \overline{F}_{k}
\end{equation}

is pure and has dimension \(\dim F_{k}-1\).

In this case, we say that \(F_{1},F_{2},\ldots,F_{t}\) is a *shelling* of \(\Delta\).
#+end_definition

#+label: exa:square-shelling
#+name: exa:square-shelling
#+begin_exampleblock
Consider the boundary of a square with vertices \(V=\{1,2,3,4\}\). The facets are the edges:
\[F_1=\{1,2\},  F_2=\{2,3\},  F_3=\{3,4\},  F_4=\{1,4\}\]
This order is a shelling. We check the intersection of each new facet with the previous ones:
1. \(\overline{F}_2 \cap \overline{F}_1 = \overline{\{2\}}\). This is the 0-simplex generated by vertex 2, which is pure of dimension 0.
2. \(\overline{F}_3 \cap (\overline{F}_1 \cup \overline{F}_2) = \overline{F}_3 \cap \overline{F}_2 = \overline{\{3\}}\). This is the 0-simplex generated by vertex 3, pure of dimension 0.
3. \(\overline{F}_4 \cap (\overline{F}_1 \cup \overline{F}_2 \cup \overline{F}_3) = \overline{\{1\}} \cup \overline{\{4\}}\). This consists of two 0-simplices (generated by 1 and 4 respectively), which is pure of dimension 0.
In all steps, the intersection is a pure complex of dimension \(\dim(F_k)-1 = 0\).
#+end_exampleblock

#+label: Prop:2
#+name: Prop:2
#+begin_proposition
The order \(F_{1},F_{2},\ldots,F_{t}\) is a shelling of \(\Delta\) if and only if for all \(i,k\) with \(1\leq i < k\leq t\) there exist \(1\leq j < k\) and \(x\in F_{k}\) such that \(F_{i}\cap F_{k}\subseteq F_{j}\cap F_{k}=F_{k}-\{x\}\).
#+end_proposition

Let us verify this proposition with the shelling order from Example [[exa:square-shelling]]. The facets are \(F_1=\{1,2\}\), \(F_2=\{2,3\}\), \(F_3=\{3,4\}\), and \(F_4=\{1,4\}\). We must check the condition for all pairs \((i,k)\) where \(1\leq i < k \leq 4\). This condition provides a more local and combinatorial way to check for shellability, which can be easier to handle than the geometric condition from Definition 2.

-  Case \(k=2\): We have \(i=1\). We compute the intersection \(F_1 \cap F_2 = \{1,2\} \cap \{2,3\} = \{2\}\). We need to find \(j < 2\) (so \(j=1\)) and \(x \in F_2\) such that \(F_1 \cap F_2 \subseteq F_j \cap F_2 = F_2 - \{x\}\). With \(j=1\), the condition becomes \( \{2\} \subseteq F_1 \cap F_2 = F_2 - \{x\} \). This is satisfied because \(F_1 \cap F_2 = \{2\}\) and choosing \(x=3 \in F_2\), since \(F_2 - \{3\} = \{2\}\). The condition holds.

-   Case \(k=3\):
    - For \(i=1\): The intersection is \(F_1 \cap F_3 = \{1,2\} \cap \{3,4\} = \emptyset\). We need to find \(j < 3\) and \(x \in F_3\) such that \(\emptyset \subseteq F_j \cap F_3 = F_3 - \{x\}\). This simply means we need to find some facet \(F_j\) with \(j<3\) that intersects \(F_3\) in a single vertex (a codimension-one face). Let's pick \(j=2\). Then \(F_2 \cap F_3 = \{2,3\} \cap \{3,4\} = \{3\}\). This equals \(F_3 - \{4\}\). So we have found \(j=2\) and \(x=4\) that satisfy the condition.
    - For \(i=2\): The intersection is \(F_2 \cap F_3 = \{2,3\} \cap \{3,4\} = \{3\}\). We need \(j < 3\) and \(x \in F_3\) such that \(\{3\} \subseteq F_j \cap F_3 = F_3 - \{x\}\). We can choose \(j=2\) and \(x=4\). Then \(F_2 \cap F_3 = \{3\}\) and \(F_3 - \{4\} = \{3\}\), so the condition holds.

-  Case \(k=4\): 
    - For \(i=1\): The intersection is \(F_1 \cap F_4 = \{1,2\} \cap \{1,4\} = \{1\}\). We can choose \(j=1\) and \(x=4\), which gives \(F_1 \cap F_4 = \{1\}\) and \(F_4 - \{4\} = \{1\}\). The condition holds.
    - For \(i=2\): The intersection is \(F_2 \cap F_4 = \{2,3\} \cap \{4,1\} = \emptyset\). We need to find \(j < 4\) and \(x \in F_4\) such that \(\emptyset \subseteq F_j \cap F_4 = F_4 - \{x\}\). If we take \(j=1\), then \(F_1 \cap F_4 = \{1\} = F_4 - \{4\}\).
    - For \(i=3\): The intersection is \(F_3 \cap F_4 = \{3,4\} \cap \{1,4\} = \{4\}\). We can choose \(j=3\) and \(x=1\), which gives \(F_3 \cap F_4 = \{4\}\) and \(F_4 - \{1\} = \{4\}\). The condition holds.

Since the condition is satisfied for all pairs \((i,k)\) with \(i<k\), the proposition is verified for this example.

* The Restriction Function
:PROPERTIES:
:CUSTOM_ID: sec:restriction-function
:END:

If \(F_{1},F_{2},\ldots,F_{t}\) is a linear ordering of the facets of the complex \(\Delta\), we will use the notation:

#+name: eq:9
\begin{equation}
\Delta_{i}=\cup_{j=1}^{i}\overline{F}_{j},\qquad \Delta_{0}=\emptyset.
\end{equation}

#+label: Def:3
#+name: Def:3
#+begin_definition
Given a linear order \(F_{1},F_{2},\ldots,F_{t}\) of the facets of a complex \(\Delta\), we define the restriction function \(\mathcal{R}\colon \{F_{1},\ldots,F_{t}\}\to\Delta\) as:

#+name: eq:2
\begin{equation}
\mathcal{R}(F_{k})=\{\,x\in F_{k}\mid F_{k}-\{x\}\in\Delta_{k-1}\,\}
\end{equation}
#+end_definition

#+label: exa:restriction-calc
#+name: exa:restriction-calc
#+begin_exampleblock
Using the square shelling from Example [[exa:square-shelling]] (\(F_1=\{1,2\}, F_2=\{2,3\}, F_3=\{3,4\}, F_4=\{1,4\}\)), we calculate the restriction sets \(\mathcal{R}(F_k)\):

1. For \(F_1\), \(\Delta_0 = \emptyset\), so no subset is in \(\Delta_0\). \(\mathcal{R}(F_1) = \emptyset\).
2. For \(F_2\), only the vertex \(2\in F_{2}\) is in \(\Delta_1\). Removing 3 gives \(\{2\} \in \Delta_1\). Removing 2 gives \(\{3\} \notin \Delta_1\). Thus, \(\mathcal{R}(F_2) = \{3\}\).
3. For \(F_3\), similarly, the vertex \(\{3\}\) is already present. \(\mathcal{R}(F_3) = \{4\}\).
4. For \(F_4\), both \(\{4\}\) (from \(F_3\)) and \(\{1\}\) (from \(F_1\)) are in \(\Delta_3\). Removing 1 gives \(\{4\} \in \Delta_3\). Removing 4 gives \(\{1\} \in \Delta_3\). Thus, \(\mathcal{R}(F_4) = \{1, 4\} = F_4\).
#+end_exampleblock

#+label: Prop:3
#+name: Prop:3
#+begin_proposition
If the order \(F_{1},F_{2},\ldots,F_{t}\) is indeed a shelling, then for \(k=1,\ldots, t\) we have that:

#+name: eq:3
\begin{equation}
\overline{F}_{k}-\Delta_{k-1}=[\mathcal{R}(F_{k}),F_{k}]
\end{equation}
#+end_proposition

That is, in this case, when adding \(\overline{F}_{k}\) to \(\Delta_{k-1}\) to form \(\Delta_{k}\), exactly one interval of new faces is added.

#+label: Theor:1
#+name: Theor:1
#+begin_theorem
Let \(F_{1},F_{2},\ldots,F_{t}\) be a linear order of the facets of a complex \(\Delta\) and \(\mathcal{R}\colon \{F_{1},\ldots,F_{t}\}\to\Delta\) a function.

Then the following statements are equivalent:
1. \(F_{1},F_{2},\ldots,F_{t}\) is a shelling and \(\mathcal{R}\colon \{F_{1},\ldots,F_{t}\}\to\Delta\) is its restriction function.
2. For all \(k=1,\ldots, t\) and \(F\subseteq F_{k}\) we have that
   #+name: eq:4
   \begin{equation}
   F\in\Delta_{k-1}\iff \mathcal{R}(F_{k})\nsubseteq F.
   \end{equation}
3. \(\Delta_{k}=\cup_{i=1}^{k} [\mathcal{R}(F_{k}),F_{k}]\) for all \(k=1,\ldots, t\).
4. \(\Delta=\cup_{i=1}^{t} [\mathcal{R}(F_{t}),F_{t}]\), and furthermore \(\mathcal{R}(F_{i})\subseteq F_{j}\) implies \(i\leq j\) for \(1\leq i,j\leq t\).
#+end_theorem

Note that the condition 4 of this theorem gives a decomposition of the shellable complex \(\Delta\). Let us see what this condition means for the shelling of the boundary of the square. For \(i=1\): \([\mathcal{R}(F_1), F_1] = [\emptyset, \{1,2\}]\). This interval consists of all subsets of \(\{1,2\}\), that is:
\[ [\mathcal{R}(F_1), F_1] = \{\emptyset, \{1\}, \{2\}, \{1,2\}\} \]
This is the complete simplex \(\overline{F_1}\). This happens if and only if \(\mathcal{R}(F_1) = \emptyset\), which is always true for the first facet in any shelling.

For \(i=2\): \([\mathcal{R}(F_2), F_2] = [\{3\}, \{2,3\}]\). This interval consists of all faces containing \(\{3\}\) and contained in \(\{2,3\}\), that is, \[ [\mathcal{R}(F_2), F_2] = \{\{3\}, \{2,3\}\} \]. These are precisely the "new" faces added when we attach the edge \(F_2\). The face \(\{2\}\) was already present in \(\Delta_1\), so it's not part of this set.

For \(i=3\): \([\mathcal{R}(F_3), F_3] = [\{4\}, \{3,4\}]\). This interval consists of all faces containing \(\{4\}\) and contained in \(\{3,4\}\), that is: \[ [\mathcal{R}(F_3), F_3] = \{\{4\}, \{3,4\}\} \]
Again, these are the new faces contributed by attaching \(F_3\). The face \(\{3\}\) was already part of \(\Delta_2\).

For \(i=4\): \([\mathcal{R}(F_4), F_4] = [\{1,4\}, \{1,4\}]\). This interval consists of faces containing \(\{1,4\}\) and contained in \(\{1,4\}\). There is only one such face. \[ [\mathcal{R}(F_4), F_4] = \{\{1,4\}\} \]
In this final step, both vertices \(\{1\}\) and \(\{4\}\) were already present in \(\Delta_3\). The only new face is the edge \(\{1,4\}\) itself.

It is immediate that:
\begin{align*} \cup_{i=1}^{4} [\mathcal{R}(F_{i}),F_{i}] &= \{\emptyset, \{1\}, \{2\}, \{1,2\}\} \cup \{\{3\}, \{2,3\}\} \cup \{\{4\}, \{3,4\}\} \cup \{\{1,4\}\} \\ &= \{\emptyset, \{1\}, \{2\}, \{3\}, \{4\}, \{1,2\}, \{2,3\}, \{3,4\}, \{1,4\}\}\end{align*}
This is precisely the set of all faces of our complex \(\Delta\), the boundary of the square. The decomposition holds.

#+label: Def:4
#+name: Def:4
#+begin_definition
Suppose that \(0\leq r\leq s\leq\dim\Delta\). We then define the following subcomplex of \(\Delta\):

#+name: eq:5
\begin{equation}
\begin{split}
\Delta^{(r,s)}=\{\,A\in\Delta\mid\dim A\leq s \text{ and }A\subseteq F\\
\text{ for some facet }F\text{ with }\dim F\ge r\,\}
\end{split}
\end{equation}
#+end_definition

#+label: exa:skeleton
#+name: exa:skeleton
#+begin_exampleblock
The most common instance of this definition is \(\Delta^{(0,s)}\), which is simply the \(s\)-skeleton of \(\Delta\) (the collection of all faces of dimension \(\leq s\)).
For example, if \(\Delta\) is a solid tetrahedron (dimension 3), \(\Delta^{(0,1)}\) is the graph formed by its edges and vertices (1-skeleton).
#+end_exampleblock

#+label: Prop:4
#+name: Prop:4
#+begin_proposition
If \(\Delta\) is shellable, then \(\Delta^{(r,s)}\) is also shellable.
#+end_proposition

* Topological Properties

:CUSTOM_ID: sec:topological-properties
:END:

#+label: Theor:3
#+name: Theor:3
#+begin_theorem
Let \(F_{1},F_{2},\ldots,F_{t}\) be a shelling of \(\Delta\) with restriction \(\mathcal{R}\) and \(\dim\Delta=d-1\).

Let \(s_{j}=|\{\,i : |F_{i}|=j, \mathcal{R}(F_{i})=F_{i}\,\}|\). Then \(\Delta\) has the homotopy type of a wedge of spheres, where there are \(s_{j}\) copies of the \((j-1)\)-sphere, for \(1\leq j\leq d\).
#+end_theorem

#+label: Cor:1
#+name: Cor:1
#+begin_corollary
If \(\Delta\) is shellable, \(H_{*}(\Delta,\mathbb{Z})\) is free.
#+end_corollary

* Partially Ordered Sets
:PROPERTIES:
:CUSTOM_ID: sec:posets
:END:

Given a finite partially ordered set (poset), one can associate the simplicial complex with vertices \(P\):

#+name: eq:6
\begin{equation}
\Delta(P)=\{\,\{x_{0},\ldots,x_{k}\}\subseteq P\mid x_{0}<x_{1}<\cdots<x_{k}\,\}.
\end{equation}

The complex \(\Delta(P)\) is called the *order complex* of \(P\).

We say then that the poset \(P\) is shellable if \(\Delta(P)\) is shellable.

We will also use the following notation and terminology: If \(P\) is a poset and \(x,y\in P\) are such that \(x\leq y\), then \([x,y]=\{\,z\in P\mid x\leq z\leq y\,\}\).

We say that \(y\) *covers* \(x\) if \([x,y]=\{x,y\}\); we denote this by \(x\to y\).

Let \(\mathcal{E}(P)=\{\,(x,y)\in P\times P\mid x\to y\,\}\) be the set of *edges* of \(P\).

If \(c\) is the chain in P: \(c: x_{0}<x_{1}<\cdots<x_{k}\), the *length* of \(c\), \(l(c)\), is \(k\).

The length of \(P\) is
#+name: eq:7
\begin{equation}
l(P)=\max_{c \text{ chain in }P} l(c).
\end{equation}

The poset \(P\) is *bounded* if it has a minimum element \(\hat{0}\) and a maximum element \(\hat{1}\).

#+label: Def:5
#+name: Def:5
#+begin_definition
Let \(P\) be a bounded poset. An *EL-labeling* of \(P\) is a function \(\lambda\colon \mathcal{E}(P)\to\Lambda\), where \(\Lambda\) is a poset, such that for all \(x,y\in P\) with \(x\leq y\) we have that:

1. There exists a unique maximal chain \(m_{[x,y]}\) from \(x\) to \(y\), \(m_{[x,y]}=(x=x_{0}<x_{1}<\cdots<x_{k}=y)\) such that
   #+name: eq:8
   \begin{equation}
   \lambda(x_{0}<x_{1})<_{\Lambda}\lambda(x_{1}<x_{2})<_{\Lambda}\cdots
   <_{\Lambda}\lambda(x_{k-1}<x_{k})
   \end{equation}
   (we will denote this collection of \(k\) elements of \(\Lambda\) henceforth by \(\lambda(m_{[x,y]})\)).

2. If \(m'\) is another maximal chain in \([x,y]\) then \(\lambda(m')>\lambda(m_{[x,y]})\) in the lexicographical order of chains of elements of \(\Lambda\).

If \(P\) has an EL-labeling, we say it is *lexicographically shellable*.
#+end_definition

#+label: exa:boolean-algebra
#+name: exa:boolean-algebra
#+begin_exampleblock
Let \(B_n\) be the Boolean algebra of rank \(n\) (subsets of \(\{1, \dots, n\}\) ordered by inclusion). We define an edge labeling \(\lambda\) as follows: if \(B = A \cup \{x\}\) covers \(A\), then \(\lambda(A, B) = x\). We order the labels \(1 < 2 < \dots < n\).

This is an EL-labeling:
- *Unique increasing chain:* For any interval \([A, B]\), the unique increasing chain is formed by adding the elements of \(B \setminus A\) in increasing order of their values.
- *Lexicographical minimality:* Any other chain must add a larger element before a smaller one, making it lexicographically larger than the unique increasing chain.

Therefore, the Boolean algebra is lexicographically shellable.
#+end_exampleblock

#+label: Theor:4
#+name: Theor:4
#+begin_theorem
Let \(P\) be a bounded poset and let \(\overline{P}=P-\{\hat{0},\hat{1}\}\). If \(P\) is lexicographically shellable, then \(\overline{P}\) is shellable.
#+end_theorem
